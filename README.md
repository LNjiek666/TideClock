## 免费部署

本项目通过 GitHub Pages 托管，使用免费的 `github.io` 域名，无需登录网站，也无需购买服务器或域名。国内网络的可用性取决于当地运营商和线路，不能保证所有网络都稳定直连。

仓库设置中的 **Settings → Pages → Source** 选择 **GitHub Actions**。向 `main` 推送代码后，`.github/workflows/pages.yml` 会检查脚本、运行计时测试，再将 `dist/` 自动部署到 GitHub Pages。无需安装项目依赖或设置密钥。

所有网站资源使用相对路径，支持 `/TideClock/` 项目路径。计划、设置与计时状态保存在访客自己的浏览器中；更换域名、浏览器或设备后不会自动迁移。

浏览器里的大屏时钟与专注空间。设计和交互参考 [FocusTide](https://github.com/Hanziness/FocusTide)，独立实现，没有复制其源码或素材。

## 使用

安装 Node.js 后，在本目录运行 `npm start`，打开 http://127.0.0.1:4173 。静态文件在 `dist/`，也可部署到 HTTPS 静态托管。

- 时钟：首页仅显示小时与分钟，超大粗体居中，支持 12/24 小时制、全屏和沉浸模式。主页默认白色，下方保留今日计划与番茄专注卡片；专注阶段为高饱和纯色，设置中可分别自定义时钟、专注、短休息和长休息的颜色。其他界面文字优先使用设备本地的苹方粗体；未安装苹方的设备会使用系统中文粗体。
- 专注：默认 25 分钟专注、5 分钟短休息，每 4 轮后休息 15 分钟。可自定义时长、周期、阶段结束行为，支持分秒/近似分钟/百分比显示。
- 计划：添加、完成划线、筛选、选择专注任务、移除及撤销。数据保存在当前浏览器，不跨设备同步。
- 总结：完成一个阶段时显示本轮完成的计划、提示音、可选桌面通知与烟花。手动跳过不计入已完成番茄。
- 桌面小窗：优先使用 Document Picture-in-Picture，支持置顶及暂停/下一阶段；其次尝试视频画中画。推荐桌面 Chrome/Edge，须通过 HTTPS 或 localhost 打开。浏览器页面内嵌、网站权限或不支持的浏览器可能限制小窗与全屏。
- 快捷键：空格开始/暂停，F 全屏，Esc 退出沉浸模式。输入和弹窗中不会触发。

计时以绝对结束时间计算，切后台或刷新后能恢复。保持主网页打开以接收结束提醒；电脑休眠期间无法发出通知，唤醒后会核对时间并显示总结。一次只在一个主页面运行计时，小窗与该页面共享计时器。

## 验证

`npm test` 验证计时漂移、暂停恢复、完成幂等、任务统计和长休息循环；`npm run check` 检查脚本语法。
